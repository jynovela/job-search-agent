# Candidate settings

Fill this in once. Every skill reads it instead of hard-coding personal details.

- **Name on documents:** <Full Name>
- **Name in file names:** <Name> (also set `file_name` in `tools/config.json`)
- **Contact line:** <phone> | <email> | <City, ST> | <linkedin.com/in/...>
- **Target roles:** <e.g. Senior Software Engineer, Marketing Manager, Director of Product>
- **Target level:** <e.g. Senior, Staff, Manager, Director>. Interview stories and scoring use this level unless a req says otherwise.
- **Capabilities file:** <e.g. `interview/product-manager-capabilities.md`>, the list of what interviews for this kind of role test. The repo ships one for product managers. For another kind of role, point to your own file, or ask the agent to create `interview/<role>-capabilities.md` using the product manager file as the model.
- **Time zone:** <e.g. US Central>. All dates use it, never UTC.
- **Downloads folder:** <e.g. /Users/you/Downloads>, where finished PDFs are saved
- **Job-search repo:** <owner>/<repo>, the private repo that holds your filled-in files
